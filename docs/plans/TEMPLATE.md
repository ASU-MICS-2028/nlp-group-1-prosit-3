# Plan for #N: the issue title

`status` moves from `planned` to `doing` to `done`.

## Goal

One or two sentences: what will exist when this is finished, and why the project needs it.

## Steps

1. Each step, small enough to finish and write down in one sitting.

## Alternatives to compare

- What else could be done at each important step, and how the options will be compared (same data, same measure: `common/score.py` on `common/test_set.csv`).

## Failure cases

- What could go wrong (bad audio, empty transcripts, running out of GPU memory, a run that diverges, the network dropping) and how each will be tested.

## GPU cost estimate

Provider, GPU, hours, rough USD for each planned run. "None" if no GPU is needed.
