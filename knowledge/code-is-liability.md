# Code is liability: submit the smallest code that does the job

The instructor's rule: **every extra line is something to maintain, secure and explain.** More code means a bigger attack surface, and the viva can pick any submitted file.

**In practice:** use a library call over a hand-written version when the library is standard (jiwer for WER). Delete experiments that didn't make it into the report, or keep them at a tag. Don't add options nobody uses.
